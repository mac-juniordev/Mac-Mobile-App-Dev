# 📱 Mac Mobile Apps

A collection of mobile applications built with React Native and Expo as part of my journey to becoming a professional mobile developer.

## Projects

| Project | Description | Status |
|---------|-------------|--------|
| Dwelr | Real estate marketplace | 🚧 In Progress |
| DentCare | AI-powered dental care companion | 🚧 In Progress |
| Rythmic | Music streaming application | 📝 Planning |

## Tech Stack

- **Mobile:** React Native, Expo, TypeScript, Expo Router, NativeWind
- **State:** Zustand, React Query
- **Backend:** Node.js, Express, MongoDB
- **Auth:** Clerk (Dwelr), JWT (DentCare)

## Goals

- Build production-ready mobile applications
- Learn modern React Native architecture
- Improve UI/UX design skills
- Explore native device capabilities
- Create reusable components and hooks
